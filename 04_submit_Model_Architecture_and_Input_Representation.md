# Model Architecture and Input Representation

SSIF is a single-station multitask Transformer model that forecasts final peak CWA intensity at each reporting station from that station's own partial 1 Hz intensity sequence. The architecture is inspired by wav2vec 2.0 but omits the speech-oriented components of that framework, retaining only the core convolutional feature extraction and Transformer-based contextual modeling. Seven independent models are trained, one for each early window length (10, 15, 20, 25, 30, 35, and 40 s). For each station–event pair, the input is a fixed-length sequence of 1 Hz intensity values within the origin-referenced early window. The intensity class is scaled to [0, 1] by dividing by 9, and a binary validity mask is concatenated as a second channel. The mask marks whether each second's observation is valid (1) or missing (0), serving three purposes: distinguishing genuine zero intensity from missing data, excluding invalid time steps from self-attention, and restricting the pooling layer to valid observations only. No per-sample z-score normalization is applied, preserving the absolute intensity scale. The model receives no epicenter, magnitude, depth, source-to-station distance, waveform data, or GMPE estimates, and each station–event record is processed independently without cross-station aggregation.

The encoder begins with a three-layer 1-D convolutional stem (Conv1d, kernel size 3) that maps the two-channel input to a 192-dimensional representation through a channel progression of 96, 192, and 192. Each convolutional layer is followed by GroupNorm with 8 groups, GELU activation, and dropout. A learnable positional embedding is added to the stem output to inject temporal order information. A 4-layer Transformer encoder with 4 attention heads, hidden size 192, feed-forward multiplier 2, dropout 0.1, and a pre-norm architecture then processes the sequence. Self-attention allows each time step to attend to all others, capturing both local intensity changes and nonlocal temporal patterns, while invalid time steps are excluded from attention computation via the validity mask.

The Transformer output is aggregated across the time dimension by a masked mean-pooling layer, producing a single fixed-length 192-dimensional vector per station–event record. Only valid time steps contribute to this average; missing positions are excluded. This pooled representation serves as the shared backbone output that drives two task-specific output heads. The design ensures that the backbone must simultaneously encode features useful for fine-grained intensity classification, binary alert detection, and ordinal estimation, rather than optimizing for any single objective. The entire architecture—stem, positional encoding, Transformer encoder, and pooling—is shared across both heads and jointly optimized, following the multitask learning paradigm in which multiple related objectives share a common representation so that each task regularizes the others.

## Multitask Optimization and Evaluation Framework

The pooled representation vector drives two linear output heads: a 10-class intensity head (Linear → 10 logits → softmax) that predicts the full CWA intensity class distribution, and a binary alert head (Linear → 1 logit → sigmoid) that predicts whether the final peak intensity will reach class 4 or above. The network is trained by jointly optimizing a composite loss of four weighted components. Class cross-entropy (weight 0.45) serves as the primary classification objective, teaching the shared backbone to discriminate among all 10 CWA intensity classes. Binary alert BCE (weight 0.35) directly optimizes the alert head for the I ≥ 4 detection task, with a positive-class weight compensating for the severe class imbalance in which only approximately 5% of records are positive. Ordinal regression (weight 0.15) exploits the ordered structure of the CWA scale, using smooth L1 loss between the probability-weighted expected class and the true class index to encourage well-calibrated predictions, especially for borderline cases. A consistency loss (weight 0.05) couples the two heads by penalizing disagreement between the alert head's sigmoid output and the class head's cumulative probability for classes ≥ 4, providing cross-head self-regularization.

Training uses the AdamW optimizer with a learning rate of 3 × 10⁻⁴, weight decay of 1 × 10⁻², warmup ratio of 0.10, batch size of 16, and a maximum of 30 epochs with early stopping patience of 6. Each prediction window is trained as an independent subprocess on a dedicated GPU, with the full pipeline across all seven early window lengths (10–40 s) completing in under 2 hours on 4 × NVIDIA L40S. Model selection proceeds in two stages: the best epoch is selected by validation average precision (AP), and the alert probability threshold is then calibrated on a separate subset to the highest value maintaining precision ≥ 0.90. This separation prevents the threshold from being optimized on the same data used for epoch selection. All reported results are from the independent testing split, evaluated once after all model selection is complete, providing an unbiased estimate of generalization.

Evaluation is defined at two levels. At the station level, contingency counts (TP, FP, FN, TN) yield precision, probability of detection (POD), F1, false-positive rate, and miss rate for the binary alert task, along with class accuracy, off-by-one accuracy, and mean absolute error for the 10-class prediction. A persistence baseline—predicting that the final class equals the maximum observed within the window—provides a reference with perfect precision but limited recall, and anticipatory positive recall isolates genuine pre-threshold forecasting skill. At the event level, a region-based detection criterion anchored to 47 reference points covering all Taiwanese counties requires at least 3 co-located stations within a 30 km radius to agree, ensuring spatial consistency. SSIF is compared retrospectively with the operational eBEAR system using matched testing events, decomposing region-positive events into both-detect, SSIF-only, eBEAR-only, and both-miss categories to characterize their complementary failure modes.
