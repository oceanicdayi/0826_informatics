# Data Partitioning and Model Selection Protocol

Partitioning was performed at the earthquake (event) level: all station records from the same earthquake remain in the same split, preventing information leakage that would inflate testing performance. Stratification used 0.5-magnitude bins to balance magnitude distributions across splits, so that training is not dominated by small events and testing is not dominated by large events. The random seed 20260803 ensures full reproducibility. The resulting splits are training (670 events, ≈70%), validation (147 events, ≈15%), and testing (147 events, ≈15%). The magnitude means are nearly identical across splits (4.29–4.31), confirming that the stratification successfully balanced the distributions. The same common cohort of 76,565 station–event records is retained for every early window length from 10 to 40 s, ensuring that performance differences across windows reflect observation time rather than sample composition.

The validation split is further subdivided into three roles to support a two-stage model selection procedure that keeps epoch selection and threshold calibration separate. The validation subset (73 events) is used to select the best training epoch via average precision (AP) with early stopping. Once the epoch is fixed, the calibration subset (36 events) is used to select the alert probability threshold—the highest value that maintains precision ≥ 0.90, the operational constraint. An internal test subset (36 events) provides monitoring during training. This separation prevents overfitting to any single decision: the threshold is not optimized on the same data used for epoch selection, and neither subset accesses the testing split.

All results reported in this study are from the independent 147-event testing split, which was never accessed during training, epoch selection, or threshold calibration. It is evaluated once, after all model selection is complete, providing an unbiased estimate of generalization performance. The three splits span similar time periods (2018–2026) with substantial temporal overlap; the testing split includes the 2018-02-06 M6.2 Hualien earthquake, which predates the earliest training event. The training–testing F1 gap is at most 7.8 percentage points, indicating minimal overfitting and confirming that the event-disjoint split and two-stage model selection procedure effectively safeguard generalization.
