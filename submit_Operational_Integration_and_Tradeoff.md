# Operational Integration and the Anticipatory–Confirmatory Tradeoff

The central insight of this study is that partial station-level intensity sequences contain two qualitatively different types of information whose balance shifts with observation time. Anticipatory information, extracted from the evolving intensity trajectory before the threshold is locally observed, enables the model to predict future shaking that the persistence baseline cannot detect by construction. Confirmatory information, available once the station has observed ≥4, enables reliable verification of arrived shaking. At short windows (10–15 seconds), most ≥4 stations have not yet locally observed ≥4, so detections are predominantly anticipatory—genuine predictions from sparse P-wave-dominated sequences with low POD but meaningful advance warning. At long windows (35–40 seconds), most ≥4 stations have already crossed the threshold, so detections are predominantly confirmatory—near-perfect POD but diminishing lead time. The 20-second window represents the optimal balance, where region-based event-level POD reaches 1.000 while the median lead time remains 6 seconds with 60.1% of detections providing ≥5 seconds of advance warning.

Region-based event detection provides a robust and operationally meaningful evaluation framework. Using 47 predefined reference points covering all Taiwanese counties as centers for on-site EEW alert regions (30 km radius, ≥3 stations with I≥4), SSIF achieved region-based POD of 1.000 from the 20-second window onward with zero misses, and precision of 1.000 from 25 seconds onward (zero false alarms). In a retrospective comparison with the operational eBEAR system on 50 matched testing events (39 region-positive), SSIF detected 2 events that eBEAR missed—earthquakes where source-parameter estimation produced magnitudes near the triggering threshold but did not issue a regional alert. The union POD reached 1.000 from 20 seconds, meaning no region-positive event was missed by both systems simultaneously. eBEAR provides faster alerts (median ~15 seconds), but SSIF provides an independent observation-based pathway for events where source characterization fails, demonstrating fundamentally different and complementary failure modes.

SSIF quantifies this trade-off with per-window metrics—POD, anticipatory positive recall, and lead-time distribution—that allow system designers to calibrate the operational window against the downstream cost function of false alarms versus missed alerts. These measurements provide the quantitative basis for designing a multi-pathway EEW architecture: eBEAR for rapid initial alerts when source characterization succeeds (typically 6–15 seconds), SSIF at the 20-second window for supplementary detection of events eBEAR misses (particularly moderate-magnitude events near the triggering threshold where source-parameter estimation is uncertain), and SSIF at 35–40 seconds as a reliable confirmation pathway with zero false alarms. The two systems fail under fundamentally different conditions—eBEAR when source characterization is uncertain, SSIF when observation time is insufficient—and their combination eliminates the residual misses of either system alone, offering a practical path toward more comprehensive earthquake early warning in Taiwan.
