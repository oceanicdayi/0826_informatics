# Model Architecture and Input Representation

SSIF is a single-station multitask Transformer model that forecasts final peak CWA intensity at each reporting station from that station's own partial 1 Hz intensity sequence. The architecture is inspired by wav2vec 2.0 but omits the speech-oriented components of that framework, retaining only the core convolutional feature extraction and Transformer-based contextual modeling. Seven independent models are trained, one for each early window length (10, 15, 20, 25, 30, 35, and 40 s). For each station–event pair, the input is a fixed-length sequence of 1 Hz intensity values within the origin-referenced early window. The intensity class is scaled to [0, 1] by dividing by 9, and a binary validity mask is concatenated as a second channel. The mask marks whether each second's observation is valid (1) or missing (0), serving three purposes: distinguishing genuine zero intensity from missing data, excluding invalid time steps from self-attention, and restricting the pooling layer to valid observations only. No per-sample z-score normalization is applied, preserving the absolute intensity scale. The model receives no epicenter, magnitude, depth, source-to-station distance, waveform data, or GMPE estimates, and each station–event record is processed independently without cross-station aggregation.

The encoder begins with a three-layer 1-D convolutional stem (Conv1d, kernel size 3) that maps the two-channel input to a 192-dimensional representation through a channel progression of 96, 192, and 192. Each convolutional layer is followed by GroupNorm with 8 groups, GELU activation, and dropout. A learnable positional embedding is added to the stem output to inject temporal order information. A 4-layer Transformer encoder with 4 attention heads, hidden size 192, feed-forward multiplier 2, dropout 0.1, and a pre-norm architecture then processes the sequence. Self-attention allows each time step to attend to all others, capturing both local intensity changes and nonlocal temporal patterns, while invalid time steps are excluded from attention computation via the validity mask.

The Transformer output is aggregated across the time dimension by a masked mean-pooling layer, producing a single fixed-length 192-dimensional vector per station–event record. Only valid time steps contribute to this average; missing positions are excluded. This pooled representation serves as the shared backbone output that drives two task-specific output heads. The design ensures that the backbone must simultaneously encode features useful for fine-grained intensity classification, binary alert detection, and ordinal estimation, rather than optimizing for any single objective. The entire architecture—stem, positional encoding, Transformer encoder, and pooling—is shared across both heads and jointly optimized, following the multitask learning paradigm in which multiple related objectives share a common representation so that each task regularizes the others.
